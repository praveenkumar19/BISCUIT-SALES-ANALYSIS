# 🍪 Biscuit Sales Analysis

A Python-based **Biscuit Sales Analysis and Exploratory Data Analysis (EDA)** project using **Pandas, NumPy, Matplotlib, and Seaborn**.

This project analyzes biscuit sales data to identify the best-selling biscuits, monthly sales trends, age-group preferences, and relationships between customer age and biscuit sales.

## 📌 Features

* 📊 Dataset analysis
* 🔍 Exploratory Data Analysis (EDA)
* 🧹 Missing value and duplicate checking
* 📈 Statistical analysis
* 🍪 Total sales analysis for each biscuit
* 📅 Monthly total sales analysis
* 🏆 Highest and lowest selling biscuits
* 📆 Highest and lowest sales months
* 👥 Age group classification
* 🍪 Age-wise biscuit preference analysis
* 📊 Age group vs biscuit sales analysis
* 🔥 Correlation analysis
* 📉 Multiple data visualizations

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

| Age   | Group          |
| ----- | -------------- |

| 13–19 | Teenager       |
| 20–35 | Adult          |
| 36–59 | Middle Age     |
| 60+   | Senior Citizen |

## 📊 Analysis Performed

### 1. Yearly Biscuit Sales

Calculates the total yearly sales of each biscuit and identifies the highest and lowest selling biscuits.

### 2. Monthly Sales

Calculates total biscuit sales for every month and identifies the month with the highest and lowest sales.

### 3. Monthly Biscuit Performance

Identifies which biscuit has the highest and lowest sales in each month.

### 4. Age Group Analysis

Customers are classified into different age groups based on their age.

### 5. Age-wise Biscuit Preference

Determines which biscuit has the highest sales for each customer's age.

### 6. Age Group vs Biscuit Sales

Groups the sales data according to age groups and calculates the total sales of each biscuit.

### 7. Popular Biscuit by Age Group

Identifies the most popular biscuit for each age group.

### 8. Correlation Analysis

Analyzes the correlation between customer age and biscuit sales.
